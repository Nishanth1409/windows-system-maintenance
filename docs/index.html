Features

The jobs you actually repeat

Each entry is labelled by how often it is worth running, so the menu tells you what to do instead of the other way round.

Quick Clean

Clears Windows temp folders and approved caches on demand. Personal folders are excluded by design, not by accident.

Free Disk Space

A deeper pass that also reclaims approved package and project caches from your secondary drive.

Update Windows and apps

Runs Windows Update, then winget and Chocolatey — keeping Spotify and Spicetify last so the patch is not overwritten.

Full Maintenance

DISM and SFC repair combined with the deep clean in a single scripted pass you can leave running.

Fix slow Explorer

Resets the shell caches that make Explorer crawl, then restores a saved folder view profile.

RAM Empty and App Groups

Optional standby-memory release through Sysinternals RAMMap, plus taskbar app-group plans.

Install

Install once, from anywhere

There is no installer to trust and no path to edit — the batch file adapts to its own location.

1

Clone it anywhere

Any drive works. The folder name is up to you.

git clone https://github.com/Nishanth1409/windows-system-maintenance.git SystemMaintenance
2

Install the desktop menu

Right-click Install_Menu.bat and choose Run as administrator. It rewrites the registry entries to match its own folder, so moving the folder just means running it again.

Right-click Install_Menu.bat  →  Run as administrator
3

Open it from the desktop

On Windows 11, right-click the desktop, choose Show more options, then System Maintenance.

4

Or call a script directly

Every menu entry maps to a script you can run yourself, which is useful for scheduled tasks.

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\System_QuickClean.ps1

FAQ

Good to know

Will it delete my files?

No. The scripts target Windows temp locations and approved caches. Personal folders are excluded, and each script is short enough to read before you run it.

What happens if I move the folder?

Re-run Install_Menu.bat. The menu entries are rewritten to the new path automatically.

Why is RAMMap not included?

It is a Microsoft Sysinternals tool, and this repository does not redistribute third-party binaries. Drop RAMMap64.exe into app\ yourself to enable RAM Empty.

Can I carry it on a USB stick?

Yes. MAKE_PORTABLE_PACKAGE.bat builds a copy you can move between machines.
